Create Export_API class in TSM\API namespace:

1. **register_routes()** method:
   - Route: GET /test-script-manager/v1/executions/(?P&lt;id&gt;\d+)/export
   - permission_callback: array('TSM\Security', 'check_admin_permission')
   - Args:
     - id: required, integer, sanitize_callback = absint
     - format: default = 'csv', enum = ['csv', 'json', 'excel'], sanitize_callback = sanitize_text_field

2. **export_execution(WP_REST_Request $request)** callback:
   - Get execution_id from $request->get_param('id')
   - Get format from $request->get_param('format')
   - Fetch execution data using ExportService::fetch_execution_data()
   - Return WP_Error if execution not found
   - ob_start() and ob_clean() to clear any accidental output
   - Set appropriate headers based on format:
     - CSV: Content-Type: text/csv; charset=utf-8
     - JSON: Content-Type: application/json; charset=utf-8
     - Excel: Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
   - Set Content-Disposition: attachment; filename="execution-{id}.{ext}"
   - Echo content from ExportService method
   - Call exit; to prevent WP from adding JSON wrapper
