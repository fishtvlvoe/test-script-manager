  <name>Task 1: Create CategoryService</name>
  <files>includes/services/class-category-service.php</files>
  <action>
Create CategoryService class in TSM\Services namespace:

1. **create($name)** static method:
   - Generate slug from sanitize_title($name)
   - Check if category with same name/slug exists (return WP_Error if duplicate)
   - Insert into tsm_categories table
   - Return category ID

2. **get($id)** static method:
   - Fetch category by ID from tsm_categories
   - Return array or null

3. **get_all()** static method:
   - Fetch all categories ordered by name ASC
   - Return array of categories

4. **update($id, $name)** static method:
   - Update name and slug in tsm_categories
   - Return true or WP_Error

5. **delete($id)** static method:
   - Delete category from tsm_categories
   - Delete all associations from tsm_script_tags WHERE category_id = $id
   - Return true or WP_Error

6. **get_script_categories($script_id)** static method:
   - JOIN tsm_script_tags with tsm_categories
   - Return array of categories for the script

7. **set_script_categories($script_id, $category_ids)** static method:
   - Delete all existing associations for script_id from tsm_script_tags
   - Insert new associations for each category_id
   - Return true

8. **delete_script_categories($script_id)** static method:
   - Delete all associations WHERE script_id = $script_id
   - Return true (used when deleting a script)

9. **get_scripts_by_category($category_id)** static method:
   - JOIN tsm_script_tags with tsm_scripts
   - Return array of script IDs

Include proper namespace, class docblock, PHPDoc for all methods.
  </action>

**Categories_API** (TSM\API namespace):

Register routes in register_routes():
1. GET /categories - list all categories (calls CategoryService::get_all())
2. POST /categories - create category (args: name, calls CategoryService::create())
3. GET /categories/{id} - get single category (calls CategoryService::get())
4. PUT /categories/{id} - update category (args: name, calls CategoryService::update())
5. DELETE /categories/{id} - delete category (calls CategoryService::delete())
6. GET /scripts/{id}/categories - get categories for a script (calls CategoryService::get_script_categories())
7. PUT /scripts/{id}/categories - set categories for a script (args: category_ids array, calls CategoryService::set_script_categories())

All routes require manage_options permission.

---

**Templates_API** (TSM\API namespace):

Register routes in register_routes():
1. GET /templates - list all templates (calls TemplateService::get_templates())
2. GET /templates/{id} - get single template (calls TemplateService::get_template())
3. POST /templates/{id}/create - create script from template (args: name, calls TemplateService::create_from_template())

All routes require manage_options permission.
