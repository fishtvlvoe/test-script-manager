<task type="auto">
  <name>Task 2: Create database schema with dbDelta</name>
  <files>
    includes/class-database.php
  </files>
  <action>
建立 `includes/class-database.php`：

1. 定義 DB_VERSION 常數（'1.0.0'）

2. create_tables() 靜態方法：
   - 檢查 tsm_db_version option，若版本相同則跳過
   - 使用 dbDelta() 建立 5 個資料表
   - 更新 tsm_db_version option

3. 5 個資料表 SQL（嚴格遵循 dbDelta 格式規則）：

**tsm_scripts:**
- id bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT
- name varchar(255) NOT NULL
- slug varchar(255) NOT NULL
- code longtext NOT NULL
- language varchar(20) NOT NULL DEFAULT 'php'
- created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP
- last_executed_at datetime DEFAULT NULL
- PRIMARY KEY  (id) -- 注意：兩個空格
- UNIQUE KEY slug (slug)
- KEY created_at (created_at)
- KEY last_executed_at (last_executed_at)

**tsm_script_versions:**
- id bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT
- script_id bigint(20) UNSIGNED NOT NULL
- code longtext NOT NULL
- created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP
- PRIMARY KEY  (id)
- KEY script_id (script_id)
- KEY created_at (created_at)

**tsm_execution_logs:**
- id bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT
- script_id bigint(20) UNSIGNED NOT NULL
- output longtext
- error text
- execution_time float NOT NULL DEFAULT 0
- memory_usage bigint(20) NOT NULL DEFAULT 0
- status varchar(20) NOT NULL DEFAULT 'success'
- executed_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP
- PRIMARY KEY  (id)
- KEY script_id (script_id)
- KEY executed_at (executed_at)
- KEY status (status)

**tsm_categories:**
- id bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT
- name varchar(255) NOT NULL
- slug varchar(255) NOT NULL
- created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP
- PRIMARY KEY  (id)
- UNIQUE KEY name (name)
- UNIQUE KEY slug (slug)

**tsm_script_tags:**
- script_id bigint(20) UNSIGNED NOT NULL
- category_id bigint(20) UNSIGNED NOT NULL
- PRIMARY KEY  (script_id, category_id)
- KEY category_id (category_id)

4. get_table_name() 靜態方法：回傳帶有 $wpdb->prefix 的資料表名稱

5. drop_tables() 靜態方法（供未來可能的完整移除使用，但 deactivation 不呼叫）

dbDelta 格式注意事項：
- 每個欄位獨立一行
- PRIMARY KEY 後面要有兩個空格
- 使用 KEY 不是 INDEX
- 不使用反引號
- 指定欄位長度（bigint(20)）
