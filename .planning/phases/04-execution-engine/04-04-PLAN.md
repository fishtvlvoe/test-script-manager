  <name>Task 1: Integrate format_as_table() in Result_Page::render()</name>
  <files>includes/admin/class-result-page.php</files>
  <action>
Modify Result_Page::render() to detect array data in output and call OutputFormatter::format_as_table().

**Current behavior (line 164):**
```php
$data['output_type'] = OutputFormatter::detect_output_type( $execution['output'] );
```

**Required changes:**

1. After detect_output_type(), check if output is JSON containing array data suitable for tables
2. If output_type is 'json', attempt to decode and check with is_table_data()
3. If is_table_data() returns true, call format_as_table() and store result
4. Pass both raw output and formatted table HTML to template

**Implementation:**

Add new logic in render() method between line 164 and include statement:

```php
// Detect output type for special formatting.
$data['output_type'] = OutputFormatter::detect_output_type( $execution['output'] );

// NEW: Attempt table formatting for JSON array data
$data['table_html'] = '';
if ( 'json' === $data['output_type'] ) {
    $decoded = json_decode( $execution['output'], true );
    if ( is_array( $decoded ) && OutputFormatter::is_table_data( $decoded ) ) {
        $data['table_html'] = OutputFormatter::format_as_table( $decoded );
        $data['output_type'] = 'table'; // Switch type to table for template
    }
}
```

This approach:
- Preserves existing JSON display for non-table arrays (nested objects, etc.)
- Only converts arrays that pass is_table_data() check (consistent structure)
- Template receives table_html for direct rendering
- Output type changes to 'table' so template knows to render HTML table
