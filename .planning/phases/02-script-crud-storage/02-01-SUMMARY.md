# Phase 02 Plan 01: Script Service and Dual-Write Storage Summary

**One-liner:** StorageService + ScriptService for dual-write (DB + filesystem) with rollback

## What Was Built

### StorageService (278 lines)
Filesystem operations for test scripts:
- `write_to_filesystem($slug, $code)` - Write script with wp-load.php header
- `read_from_filesystem($slug)` - Read and strip auto-generated header
- `delete_from_filesystem($slug)` - Delete script file
- `get_script_url($slug)` - Get browser-accessible URL
- `get_script_path($slug)` - Get filesystem path
- `ensure_directory_exists()` - Create {ABSPATH}/test-scripts/ with security files

**File format:**
```php
<?php
// Auto-generated by Test Script Manager
// Slug: {slug}
// WARNING: Do not edit directly - changes will be overwritten
require_once __DIR__ . '/../wp-load.php';

// User's code here...
```

### ScriptService (552 lines)
CRUD operations with dual-write pattern:
- `create($name, $slug, $code, $language)` - Insert DB + write file, rollback on failure
- `get($id)` / `get_by_slug($slug)` - Fetch with script_url added
- `update($id, $data)` - Update DB + sync file, handle slug rename
- `delete($id)` - Remove from DB + delete file
- `search($keyword, $language, $limit, $offset)` - Search by name/code/language
- `list_all($limit, $offset)` - List with pagination
- `count($keyword, $language)` - Count with optional filters
- `update_last_executed($id)` - Update timestamp

**Validation:**
- Name: required, max 255 chars
- Slug: required, sanitize_title format (a-z, 0-9, hyphens)
- Code: required, non-empty

**Rollback mechanism:**
- If `StorageService::write_to_filesystem()` fails after DB insert
- Automatically delete the DB record
- Return WP_Error with combined message

## How It Connects

```
ScriptService::create()
    |
    +--> $wpdb->insert() [Database]
    |
    +--> StorageService::write_to_filesystem() [Filesystem]
    |    |
    |    +--> ensure_directory_exists()
    |    +--> Write file with header
    |
    +--> On failure: $wpdb->delete() [Rollback]
```
