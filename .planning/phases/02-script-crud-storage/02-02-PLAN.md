  <name>Task 1: Create Scripts_API class with REST endpoints</name>
  <files>includes/api/class-scripts-api.php</files>
  <action>
建立 Scripts_API 類別,註冊 WordPress REST API 端點:

**命名空間:** `namespace TSM\API;`

**依賴:**
```php
use TSM\Security;
use TSM\Services\ScriptService;
use WP_REST_Request;
use WP_REST_Response;
use WP_Error;
```

**類別結構:**

1. **register_routes()** - 註冊所有 REST 端點
   - Hook: `rest_api_init`
   - Namespace: `test-script-manager/v1`

   **端點定義:**

   a) `POST /scripts` - 建立腳本
   ```php
   register_rest_route('test-script-manager/v1', '/scripts', [
       'methods' => 'POST',
       'callback' => [$this, 'create_script'],
       'permission_callback' => ['TSM\Security', 'check_admin_permission'],
       'args' => [
           'name' => ['required' => true, 'type' => 'string'],
           'slug' => ['required' => true, 'type' => 'string'],
           'code' => ['required' => true, 'type' => 'string'],
           'language' => ['default' => 'php', 'type' => 'string']
       ]
   ]);
   ```

   b) `GET /scripts` - 列出腳本 (支援搜尋)
   ```php
   register_rest_route('test-script-manager/v1', '/scripts', [
       'methods' => 'GET',
       'callback' => [$this, 'get_scripts'],
       'permission_callback' => ['TSM\Security', 'check_admin_permission'],
       'args' => [
           'search' => ['default' => '', 'type' => 'string'],
           'language' => ['default' => '', 'type' => 'string'],
           'limit' => ['default' => 100, 'type' => 'integer'],
           'offset' => ['default' => 0, 'type' => 'integer']
       ]
   ]);
   ```

   c) `GET /scripts/{id}` - 取得單一腳本
   ```php
   register_rest_route('test-script-manager/v1', '/scripts/(?P<id>\d+)', [
       'methods' => 'GET',
       'callback' => [$this, 'get_script'],
       'permission_callback' => ['TSM\Security', 'check_admin_permission'],
       'args' => [
           'id' => ['required' => true, 'type' => 'integer']
       ]
   ]);
   ```

   d) `PUT /scripts/{id}` - 更新腳本
   ```php
   register_rest_route('test-script-manager/v1', '/scripts/(?P<id>\d+)', [
       'methods' => 'PUT',
       'callback' => [$this, 'update_script'],
       'permission_callback' => ['TSM\Security', 'check_admin_permission'],
       'args' => [
           'id' => ['required' => true, 'type' => 'integer'],
           'name' => ['type' => 'string'],
           'slug' => ['type' => 'string'],
           'code' => ['type' => 'string'],
           'language' => ['type' => 'string']
       ]
   ]);
   ```

   e) `DELETE /scripts/{id}` - 刪除腳本
   ```php
   register_rest_route('test-script-manager/v1', '/scripts/(?P<id>\d+)', [
       'methods' => 'DELETE',
       'callback' => [$this, 'delete_script'],
       'permission_callback' => ['TSM\Security', 'check_admin_permission'],
       'args' => [
           'id' => ['required' => true, 'type' => 'integer']
       ]
   ]);
   ```

2. **create_script(WP_REST_Request $request)** - 處理建立請求
   - 取得參數: `$request->get_param('name')`, etc.
   - 呼叫: `ScriptService::create($name, $slug, $code, $language)`
   - 成功返回: `new WP_REST_Response(['success' => true, 'script_id' => $id], 201)`
   - 失敗返回: `new WP_REST_Response(['error' => $error->get_error_message()], 400)`

3. **get_scripts(WP_REST_Request $request)** - 處理列表請求
   - 取得參數: search, language, limit, offset
   - 如果有 search 參數,呼叫 `ScriptService::search()`,否則呼叫 `ScriptService::list_all()`
   - 返回: `new WP_REST_Response(['scripts' => $scripts, 'total' => count($scripts)], 200)`

4. **get_script(WP_REST_Request $request)** - 處理單一腳本請求
   - 取得 ID: `$request->get_param('id')`
   - 呼叫: `ScriptService::get($id)`
   - 如果找不到: `new WP_REST_Response(['error' => 'Script not found'], 404)`
   - 成功返回: `new WP_REST_Response($script, 200)`

5. **update_script(WP_REST_Request $request)** - 處理更新請求
   - 取得 ID 和參數
   - 呼叫: `ScriptService::update($id, $data)`
   - 成功返回: `new WP_REST_Response(['success' => true], 200)`
   - 失敗返回: `new WP_REST_Response(['error' => $error->get_error_message()], 400)`

6. **delete_script(WP_REST_Request $request)** - 處理刪除請求
   - 取得 ID
   - 呼叫: `ScriptService::delete($id)`
   - 成功返回: `new WP_REST_Response(['success' => true], 200)`
   - 失敗返回: `new WP_REST_Response(['error' => $error->get_error_message()], 400)`

**錯誤處理:**
- 所有方法都要檢查 ScriptService 返回的 WP_Error
- HTTP 狀態碼: 200 (成功), 201 (建立), 400 (錯誤), 404 (找不到)

**重要:** 不使用 nonce 驗證,改用 `permission_callback` 檢查 `manage_options` capability
WordPress REST API 已內建 cookie authentication,不需要額外 nonce
