  <name>Task 1: Create StorageService for filesystem operations</name>
  <files>includes/services/class-storage-service.php</files>
  <action>
建立 StorageService 類別處理檔案系統操作:

**路徑設定:**
- 腳本儲存目錄: `{ABSPATH}/test-scripts/` (WordPress 根目錄)
- 檔名格式: `test-{slug}.php`
- 使用 `wp_upload_dir()` 模式確保目錄可寫入
- 如果目錄不存在則自動建立 (chmod 0755)

**方法:**
1. `write_to_filesystem($slug, $code)` - 寫入腳本檔案
   - 檔案開頭加入: `<?php\n// Auto-generated by Test Script Manager\n// Slug: {slug}\nrequire_once __DIR__ . '/../wp-load.php';\n\n`
   - 然後寫入 $code 內容
   - 返回: 成功則 true,失敗則 WP_Error

2. `read_from_filesystem($slug)` - 讀取腳本檔案
   - 移除自動加入的 header (wp-load.php 那段)
   - 返回: 純 code 內容,或 WP_Error

3. `delete_from_filesystem($slug)` - 刪除腳本檔案
   - 使用 wp_delete_file() 或 unlink()
   - 返回: 成功則 true,失敗則 WP_Error

4. `get_script_url($slug)` - 取得腳本 URL
   - 返回: `https://test.buygo.me/test-scripts/test-{slug}.php`

5. `ensure_directory_exists()` - 私有方法,確保目錄存在且可寫入

**錯誤處理:**
- 目錄無法建立 → WP_Error
- 檔案無法寫入 → WP_Error
- 檔案不存在 → WP_Error

**命名空間:** `namespace TSM\Services;`
  </action>
  <verify>
PHP 語法檢查: `php -l includes/services/class-storage-service.php`
檢查檔案包含所有 5 個公開方法
  </verify>
  <done>
StorageService 類別存在,包含 write_to_filesystem, read_from_filesystem, delete_from_filesystem, get_script_url, ensure_directory_exists 方法
  </done>

<task type="auto">
  <name>Task 2: Create ScriptService for CRUD operations</name>
  <files>includes/services/class-script-service.php</files>
  <action>
建立 ScriptService 類別處理腳本 CRUD,整合 Database 和 StorageService:

**依賴:**
- `use TSM\Database;`
- `use TSM\Services\StorageService;`

**方法:**

1. `create($name, $slug, $code, $language = 'php')` - 建立腳本
   - 驗證: name 和 slug 不可為空, slug 必須是有效的 slug (a-z0-9-)
   - 插入 wp_tsm_scripts: `$wpdb->insert(Database::get_table_name(Database::TABLE_SCRIPTS), [...]);`
   - 成功後呼叫 `StorageService::write_to_filesystem($slug, $code)`
   - 如果檔案寫入失敗,回滾資料庫 (delete script)
   - 返回: script_id 或 WP_Error

2. `get($id)` - 取得單一腳本
   - 查詢: `$wpdb->get_row($wpdb->prepare("SELECT * FROM ... WHERE id = %d", $id), ARRAY_A);`
   - 添加 `script_url` 欄位: `StorageService::get_script_url($script['slug'])`
   - 返回: script 陣列或 null

3. `update($id, $data)` - 更新腳本
   - $data 可包含: name, slug, code, language
   - 如果 slug 改變,需要移動檔案 (delete old + write new)
   - 更新 wp_tsm_scripts: `$wpdb->update(...)`
   - 更新檔案系統: `StorageService::write_to_filesystem($slug, $code)`
   - 返回: 成功則 true,失敗則 WP_Error

4. `delete($id)` - 刪除腳本
   - 先取得 slug
   - 刪除資料庫記錄: `$wpdb->delete(...)`
   - 刪除檔案: `StorageService::delete_from_filesystem($slug)`
   - 返回: 成功則 true,失敗則 WP_Error

5. `search($keyword = '', $language = '', $limit = 100, $offset = 0)` - 搜尋腳本
   - 支援關鍵字搜尋 (name, code)
   - 支援語言篩選
   - 使用 LIKE 查詢: `name LIKE %{keyword}% OR code LIKE %{keyword}%`
   - 返回: scripts 陣列

6. `list_all($limit = 100, $offset = 0)` - 列出所有腳本
   - 依 updated_at DESC 排序
   - 返回: scripts 陣列

**驗證:**
- Slug 格式: 使用 `sanitize_title()` 或 regex `^[a-z0-9-]+$`
- Name 長度: 1-255 字元
- Code 不可為空

**錯誤處理:**
- 使用 WP_Error 物件
- 資料庫操作失敗 → WP_Error
- 檔案操作失敗 → WP_Error (並回滾資料庫變更)

**命名空間:** `namespace TSM\Services;`
